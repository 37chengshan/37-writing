# X｜先给判断，再给证据

1. 从用户材料挑一个能被转述、转发或理性反驳的判断；前一句就说人话，不做公众号开场白。
2. **单条**：判断 + 一项有力事实/实测细节 + 适用边界，必要时用真实问题引互动。不强行凑段数。
3. **线程**：首帖即给完整价值，第 2 帖补背景，每帖独立推进一项增量，结尾有结论和来源。不要用机械“1/10”当结构。
4. 引用评论：先准确概括被引观点，再发表自己的新增信息；不得歪曲原帖。
5. 默认普通短帖 280 加权字符预算，中文通常按两字符计；URL 常采用平台折算。**平台编辑器与当前账号权限优先**，别断言任何账户都能发布长文。
6. 标签与 emoji 克制、尊重账户本来语气；不要贴小红书格式，不要用虚假的实测数据。

**输出**：单帖正文或使用 `<!-- POST -->` 独立分隔每条的 Thread；用户指定一个版本就只给一个。必要时给扩展稿/备选 Hook。
