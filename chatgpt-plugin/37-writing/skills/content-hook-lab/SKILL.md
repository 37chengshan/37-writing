# 标题与传播潜力｜做可兑现的强承诺

## 选题五问

1. 这件事和谁的钱、时间、风险、认同或机会有关？
2. 哪个事实与常识直觉冲突？有来源吗？
3. 是否有具体人物、选择、损失、转折或证据，而不只是观点？
4. 看完的人能得到一个新判断、方法或真实故事吗？
5. 他会把哪句话转述给别人，或因何提出不同意见？

## 按平台分流

- 公众号：人物 + 反常结局；资源与代价；选择与反转；历史/商业因果；可讲清楚的故事。开头承诺必须兑现，结尾有余味。
- X：一个可讨论判断、一个不为人知的数据或一条证据；首帖读完就有价值。
- 小红书：高相关搜索词 + 人群/场景 + 真实结果；封面与前三行达成一个清晰承诺。

## 标题生成与筛选

同一篇给 **3–5 种不同机制** 的候选（反差、损失、结果、人群、搜索、选择），而不是同义改写。对每条按 0–2 记分：相关性、具体性、可信度、差异化、读者收益、兑现程度（总分 12），给出一条优先推荐和失败风险。该分值是编辑比较工具，不能用来预测实际推荐量。

## 叙事与情绪

画出“钩子→问题升级→临界选择→反转→余波”的节拍。每段回答“读者现在多知道了什么”。若出现重复背景、提前解释结局、无依据金句或不必要的平衡段落，就删/移，不加假悬念。

## 封底约束

禁止编造资产、收益、人物对话、销量、历史原话、亲历、所谓必爆公式。允许真观点有棱角，事实却必须站得住。研究来源与实测数据分开注明。
