# 公众号｜让读者一直想知道后来呢

**主笔策略**：用一个能兑现的矛盾开场，人物的选择推动因果，事实给故事重量，节奏持续发生变化。避免写成论文摘要。

1. 在第一屏直接呈现 **反常结局/具体动作/悬而未决的代价**；不写时代背景长铺垫。
2. 把人物、欲望、资源、约束、误判和代价排成可追溯时间线。每 2–4 段推进新信息/新冲突/新代价，不用“首先其次最后”。
3. 开头埋伏笔，中途要兑现或升级；结尾回扣具体物件/数字/选择，并留下可讨论的价值判断，不把全部判断替读者说死。
4. 高潮不要插入长篇史料考据或自我辩护；重大事实先在编辑阶段核实，必要注释放在正文之后。
5. 情绪波形：惊讶 → 投入 → 希望或上升 → 反转 → 代价 → 余波。它是可选模型，不能套成每篇完全一样。
6. 对爆款潜力做诚实诊断：读者关系、反常程度、故事矛盾、可信证据、增量信息、情绪强度、转述性、标题兑现。预测不等于事实。
7. 对修改任务遵守“外科手术式改稿”：优先保护已有的事实、铺垫、叙述视角与成功结构；除非用户要全篇重写。

**交付**：通常给 1 个主标题 + 3 个不同策略备选、正文、必要的待核问题；用户只要正文时不给长篇说明。标题不能许诺正文不存在的反转或编造数字。
