# ChatGPT Web：用用户手改稿训练写作偏好（非自动学习）

此流程**仅在用户提供初稿与本人改定终稿时启用**。不读取本地文件、不调用 Python、不假设自动记忆已经生效。跨会话长期生效应由用户保存到私有插件文件、项目说明或明确更新个人偏好；不能承诺 AI 会自动、永久记住。

## 五步人工学习

1. **输入**：同一文章的 AI 初稿与作者终稿；标明平台、账号及本轮写作目的。如仅有终稿，只能总结观察，不能声称知道哪些地方被删过。
2. **精准差异**：按开头钩子、事件顺序、事实与引用、断句节奏、用词、情绪强度、结尾方式归类。每条偏好附上来自这两份稿件的简短证据。
3. **剔除一次性修改**：某词被删除不等于作者永远讨厌它。将偏好先标为 `候选`；至少跨多次同类写作得到一致证据且用户认可，才标记 `已确认`。
4. **保护边界**：不要把用于外部作者的文本差异归入用户语料；不能把编辑为事实纠错的改动误当审美偏好；私人经历未经授权不能沉淀为公开模板。
5. **产物**：输出一个 5–10 条的可复制写作 DNA 卡（平台、偏好、来源片段/修改动机、置信度、反例），由用户决定是否更新私有插件。

## 回答格式示例

- 观察：首段从宏观背景移到了一个人物选择。
- 证据：初稿 XX；终稿 YY（必要短引，不超过授权原文）。
- 可能原因：开场更快兑现冲突，读者更易继续读。
- 状态：候选，等待后续稿件与用户确认；**不是永久封禁句式**。

## 平台隔离

公众号学长线悬念与叙述节奏；X 学观点前置与证据密度；小红书学人群锚点、搜索词与可扫读性。三平台共同遵守事实与个人立场，但段落长度、标题结构不能互相强制移植。
