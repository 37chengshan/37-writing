# 小红书｜让对的人停下且看完能带走东西

先判 **教程/个人故事/经验复盘/合集清单/真实测评/避雷/工具分享**；不要把所有笔记写成“姐妹们救命”的广告腔。

1. 先确定目标搜索词和具体用户场景，不堆热搜词。
2. 标题把“读者会搜的词”和一个具体价值合并；长度与限制以当前编辑器为准。
3. 前三行包含人群/困扰/实际结果或变化，后文必须兑现标题。没有亲身验证，不写“用了 30 天亲测”。
4. 正文信息可扫读：一步一个动作，一段一个结论；图片每张回答一个问题。Emoji 是可选节奏器，跟账号风格走。
5. 有真实缺点、失败边界、适用人群才可信；不要只夸不讲成本。
6. 若是商业合作、赠品、佣金或推广，按平台现行规则披露，不伪装纯个人分享。

**输出**：3 个差异化短标题 + 最佳正文 + 1–5 个搜索/场景标签候选 + 封面主张与图卡建议。用户仅要求正文就直接给成稿。
