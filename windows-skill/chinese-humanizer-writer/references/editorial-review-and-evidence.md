# 事实账本、版权与八维审稿门禁

## 事实账本：一条重要断言，一条可核对来源

`evidence-ledger.json` 最小字段：

```json
{
  "claims": [
    {
      "id": "claim-001",
      "statement": "【需要核验的准确断言】",
      "status": "unverified",
      "source_url": "",
      "source_date": "",
      "source_type": "primary | secondary | personal",
      "counterevidence": "",
      "notes": ""
    }
  ]
}
```

- `verified` 仅代表编辑核查过此断言确有对应支持，**不能只因有链接就自动标为已核实**。
- 缺来源的“官方数据显示”、数据精度、人物对话、研究结论、财报数字不可以强行通过。
- 引用要核对原词、时间与前后语境。多个不同计量口径需拆开说明，不可直接相加。
- 事实与作者分析观点分开，观点可以锋利，不能变成伪造事实。
- 老史料/新闻出现相互矛盾时：记账、选择可信版本，必要时说明“某来源记载”，不用凭空断言。
- `platform_quality_gate.py` 可以阻止「标记 verified 但没有 URL」等结构错误，**无法判断这个 URL 是否真的支持该句**；必须人审。

## 八个维度（每项可以记录 PASS/REVIEW/BLOCK）

| 维度 | 主要提问 | BLOCK 触发示例 |
|---|---|---|
| 1 事实溯源 | 钱、日期、人名、引用可逐句追到来源吗 | 无证数字被写成绝对事实 |
| 2 叙事与逻辑 | 因果清楚？转折真实？开头承诺兑现？ | 造出从未发生的事件 |
| 3 作者真实性 | 体验/身份/人设来自用户授权吗 | 把外部作者的亲历挪用 |
| 4 版权 | 图片/原文/摘录有合法使用范围吗 | 长篇复制第三方文章 |
| 5 平台适配 | 公众号长线、X 字数、小红书首屏是否达标 | X 帖子超当前上限 |
| 6 受众价值 | 新信息、具体步骤、可以讨论的真实问题是什么 | 标题承诺全文完全没兑现 |
| 7 合规与商业 | 赞助披露？是否有医疗金融误导？ | 虚构收益/疗效与广告关系 |
| 8 文风自然 | 修辞是否有价值？机械套话能否减少？ | 风格雷同严重需要人重写 |

审稿顺序：**先 BLOCK 重大事实/原创性/版权/合规 → 再 REVIEW 论证/结构/平台体验 → 最后去 AI 套话**。不要因为 AI 味分数高，就放过一个严重事实错误；也不要为了替换套话毁掉原本自然的表达。

### 三轮复核（反向思考）

- **事实编辑**：找 5 个最容易被读者挑战的断言，逐一验证来源；有争议时加注释或删掉。
- **怀疑者**：反着读标题与推理链，检查有没有过度因果、把个例当普遍规律或把推测写成现实。
- **平台读者**：看首屏是否兑现，手机端能否扫读，正文是否有情绪/信息推进而非 AI 结构堆叠。

### 重要边界

本地检查默认离线、不会访问网页，也不会连接微信/X/小红书账号。必须明确区分“脚本通过”“人工审查完成”“线上平台验证完成”三种不同状态。
