# 微信公众号：长文、故事、评论与排版

## 原则：先让读者想知道「后来呢」，再让读者收获「原来如此」

选题先确认读者读完后获得的一个价值：新的事实、一个金钱/权力/风险判断、一个可执行方法或一个真实人的命运。如果没有这个价值，空堆华丽句子也没用。

### 写前最短诊断

1. 类型：人物命运/历史悬疑/经济现象/金融机制/创业方法/工具实测/访谈；根据用户已有素材选不同写法。
2. 证据边界：用时间线列出可靠事件、直接引用及原始文献；争议版本单独记。
3. 单一主线：这篇想揭示的核心矛盾是什么？每次转折带来哪个新信息？
4. 情绪弧线：反常钩子 → 具体人物和处境 → 第一次反转 → 更深的代价 → 关键抉择 → 回扣开头。不是每篇都必须按六段对齐。

### 六种创作路由

- **访谈式**：用户只有想法时，可收集最多 3 个最值钱的细节问题；如用户要立即完稿，允许留待补锚点后继续出稿。
- **大纲式**：有论点时先做场景→论据→转折的骨架，避免把事实当目录念。
- **续写式**：找最后一个悬念和未兑现的承诺，延续用户现有叙事速度。
- **素材整合式**：大量资料先收成一条事件时间线，把会破坏主线的旁枝后移或删除。
- **破题式**：给 3–5 个不同切口，优先角色矛盾、重大选择、代价、反直觉结果。
- **定点重写式**：只改用户指出的段落，并说明被保护的数字/引文/原始事实没有变化。

### 长文的五个推进测试

- 读者读到每 2–4 段，是否知道了新事件、新证据、新代价或新问题？
- 文章中断讲道理的地方，能否改成一个人物动作、一笔账或一段因果？
- 每个悬念最终是否兑现？结尾是否呼应开头的物件、选择或金额？
- 断言的数字、财产、年份、官职、财务报表是否来自对应原始材料？冲突说法有没有区分？
- 评论空间来自真实的价值判断分歧，而不是故意留下事实错误。

**事实审查可以移到文末参考、脚注或编辑器审查报告中，不要在故事高潮插入长篇说理。** 重大错误必须纠正；没有必要把所有争议都塞进正文。

### 标题五路（每条必须与正文一致）

1. 人物 + 反常结局；2. 钱与代价的对照；3. 一个难解的选择；4. 历史反转；5. 搜索明确型。

标题不杜撰资产数、交易额或不存在的原话。稿内没有兑现的反转，不可做成标题。优先 3–5 条有明显差异的候选，而不是重复十个形容词。封面文案可以更短，但不应比标题夸张。

### 交付

默认：首选标题 + 备选标题；正文；引用出处/待核事实（可单列，不破坏故事正文）；3–5 张图的建议功能（人物证据、时间线、关键物件、数据证明等）。如果用户只要求正文，只提供正文。
