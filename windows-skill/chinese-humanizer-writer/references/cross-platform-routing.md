# 公众号 / X / 小红书跨平台母题工作流

## 一套事实，三条叙事，不用「一键改短」

```text
        [用户真实观点 + 可追溯事实 + 可用版权素材]
                          │
             唯一主张、反证、受众价值
                          │
            核心事实账本（内容不可变）
                 ┌────────┼────────┐
                 ↓        ↓        ↓
              公众号       X      小红书
            人物命运/长线  观点/证据  搜索/步骤/清单
            悬念兑现      可讨论    前三行利益与图卡
                 └────────┼────────┘
                          ↓
                 三份独立平台草稿
                          ↓
              各自标题、审查、人工发布
```

### 执行 SOP

1. 提炼一个不随平台改变的 `core_thesis`，锁死年代、人物、金额、引用与不确定性修饰词。
2. 建 `evidence-ledger.json`：事实逐条核验；不要把引用的推测当作事实。
3. 建自有账号的基调：主张、常用语言节奏与禁忌；再加载特定平台的长度与首屏约束。
4. 分别写：公众号让读者想追下去；X 先给可辩驳判断；小红书先给具象收获/图文清单。
5. **跨平台不同标题和不同信息顺序**，但不为点击率制造不同的事实版本。
6. 分别自检：公众号因果与伏笔；X 每条字数与独立信息；小红书标题、首屏、搜索词、图卡一致。
7. 人审后手动发布；平台反馈仅作为下一轮候选经验，不把一次流量结果认定为因果规律。

### 对同一主题的合法改写示例（以下为虚构练习示例，不是历史事实）

母题：虚构一家店关门后，老板才发现库存和现金不是一回事。

- 公众号钩子：关门前一个月，店里还有一屋货。账上却只剩下一周的房租。
- X 切口：一家店最大的风险，可能不是没利润，而是账面利润变不出现金。库存不能自动付房租。
- 小红书切口：开店现金流检查表：关门前最容易漏掉的 4 笔钱。拆成 4 张图并给具体计算步骤（事实/数额需独立核实）。

以上句子只展示表达差异。**不得把虚构的店铺经历当成作者亲历发稿**。
